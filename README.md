# Flow Osteopatia – strona

Statyczna strona (Eleventy) gabinetu osteopatii Aleksandry Połowniak.

- Treści: `src/_data/*.yml` (edycja przez [Pages CMS](https://app.pagescms.org), konfiguracja w `.pages.yml`)
- Zdjęcia: `src/images/`
- Lokalnie: `npm install && npm start`

## Cloudflare Pages
- Build command: `npm run build`
- Output directory: `_site`
